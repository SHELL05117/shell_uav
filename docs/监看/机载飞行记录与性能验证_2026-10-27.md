# 机载飞行记录与性能验证

工程归属2026-10-27，实际测试2026-10-28凌晨。当前是否留在RK，以[本轮实测与部署结论](../验证记录/机载飞行记录_2026-10-27/README.md)为准。源码存在不表示板端启用。

## 记录范围

本轮实现位于`tools/uav_log.py`、`uav_perf.py`、`uav_log_report.py`，并接入`uav a`／`uav check`。C窗口`uav c`／`uav mission`关联A已创建的记录；直接运行其他roslaunch不会自动开启此功能。记录器无飞控服务调用，无模式、解锁、目标或舵机命令发布。

- `core_*.bag`：白名单内的IMU、雷达、TF／地图、PX4本地位姿／里程计、融合位姿、状态／电池／RC、控制设定值／反馈、DWA速度／路径／目标／结果、任务状态／健康／数值诊断、GPIO命令／ACK及ROS日志。
- `media_*.bag`：2FPS上限的场景JPEG，以及每次实际推理所选源帧的JPEG证据。无观看客户端时，存档分支只按2FPS编码；有观看客户端时复用同一JPEG。实际推理帧由独立有界单槽线程编码，不在50Hz控制回调中编码或写盘。
- `/mission/inference`：类别／置信度／框、源图时间、源帧代次、推理耗时、完成时间、结果接受／拒绝及原因。空结果也记录；源帧JPEG是有损图像，不能称为与模型输入张量逐像素相同。图像与结果按源图时间关联，并核查缺对和队列覆盖计数。
- `/mission/audit`：阶段、任务、航点、目标位置、位姿／飞控／TF／规划指令年龄、确认次数、ACK状态和控制定时器间隔。新增下降超时继续投放／ACK超时继续爬升的明确事件，不改变原动作策略。
- `/location_node/range_audit`：通信读取后得到的测距值、读取附近的RK时间、门控接受与否、最近接受时间。协议校验失败抛异常时保留ROS警告，不把它伪造为有效距离；该时间不是TFmini内部采样时钟。
- `session.json`、`versions.json`、`deployment.json`、`command-*.json`与`parameters-*.yaml`：本轮ID、启动及任务参数、机载关键源码／模型／标定哈希、部署清单及ROS参数快照。飞控完整参数不由ROS参数快照替代；应随独立ULog／QGC参数导出保存。
- `launch-*.stdout.log`、`ros-logs/`、`events.jsonl`：启动期、程序输出、ROS日志、分架次解锁／解除武装事实和录制状态。进程直接写文件，终端镜像线程阻塞不会堵塞子进程输出。
- `performance.jsonl`：每秒读取Linux `/proc`，记录整机CPU、iowait、内存、swap、温度、磁盘写入及各进程CPU／RSS。进程100%表示占满一个核；整机CPU百分比按全部在线核归一化。

## 生命周期与空间

默认目录为RK的`~/uav_flight_logs/<日期时间>-<随机ID>/`，可用`UAV_LOG_ROOT`覆盖。RK断电可能恢复旧日期，启动ROS前核对时钟，运行中不跳改时间；同时保存boot ID与单调时间。C窗口不会另开一套录包。记录守护进程独立于SSH终端，持续记录不依赖电脑观看客户端；这不改变原飞行程序自身的SSH生命周期。

核心／图像分开录包，60秒分段，缓冲分别32／8MiB，不在RK启用高负载压缩。启动要求至少3GiB可用；运行降至2GiB先停图像、约1.1GiB停止记录。没有自动删除旧日志，不在飞行中清盘。突然断电仍可能损坏最后的活动段，不能保证零损失。影像写入失败可降级为核心记录；核心失败则记录故障并退出记录器，不杀定位、导航或控制进程。

`UAV_LOG_PROFILE=core`选择无图像的核心记录，`full`包含图像。核心模式仍保存每次推理的结构化结果和源时间，报告会明确图像未记录，不要求图像／结果配对完整。`UAV_LOG_DISABLED=1`用于对照时完全关闭本轮记录。切换应在地面启动前完成，不能据这些开关擅自把未验版本投入飞行。

在相关源码已部署的前提下，可查看和离线生成报告：

```bash
uav logs
uav logs status
uav logs report /home/jcfh/uav_flight_logs/某轮目录
```

人工`uav logs stop`只停止记录器，不停止飞行来源。源节点退出且最后已观测解除武装时，记录器可自动封包并生成报告；需要人工报告时应落地后运行，不能在空中扫描大包。磁盘不足或录制失败在终端／`/uav_log/health`报告，不自动改变飞控模式或原解锁条件。

## 分析与验证边界

离线报告保存`summary.json`、`report.md`、轨迹／设定值／模式／事件CSV和诊断JSONL，核查话题缺失、消息间隔、源时间年龄、推理帧配对及缓冲溢出。源时间缺失或跨时钟未对齐时，不据接收时间声称已测网络延迟。地面禁动运行只验证控制定时器，不能证明空中50Hz设定值发送；GPIO ACK只表示软件完成，不能证明物资实际释放。

`tools/uav_logging_benchmark.py`用真实相机、RKNN、雷达、定位和未解锁FCU做对照，两组均保留`top -b -d 2`与`vmstat 1`。`tools/uav_logging_fault_probe.py`仅在独立`127.0.0.1:11339`主机上发送合成设定值，验证录包和写入进程故障隔离；不接真实MAVROS、传感器或舵机。相关原始录制保存在本地Git忽略的`recordings/flight_logging_20261027/`，精选结果见验证目录。

PX4 ULog仍应独立核查实际固件的logger、SD卡、SDLOG参数及每次实际解锁文件。机载ROS记录不保证已经取得飞控高频原始日志，也不替代现场视频与逐级飞行验证。
