## 已部署的接续命令

在RK的SSH终端运行（同一设备只启动一套ROS系统）：

```bash
source /home/jcfh/catkin_ws/devel/setup.bash
roslaunch location rk_preflight.launch target_hazard:=flammable
```

`flammable`为观测示例，按现场类别选择，也可省略等待目标。此入口将真实定位送入PX4，运行相机／雷达／模型／DWA，任务动作门固定关闭。Ctrl+C停止本入口，NPU自启服务继续保留。与QGC或其他串口程序切换时先退出占用设备的程序。

高度配置为[0.12m现场配置](../../../src/location/param/rk_height_reference_20261027.yaml)，来源为尺量12±1cm和80帧实际取零；杆臂零值为SHELL接受的近似。通用location.launch默认未标定保持。重新安装或改变对地支撑状态时，先用真实输入重取零再更改配置。

## 修复与复现工具

[TFmini传输](../../../src/location/src/tf_mini_i2c.cpp)使用原始5字节请求与完整9字节读取，短读／短写、帧头／校验和无效距离／信号均拒收。1ms间隔来自本轮设备对照，未改传感器模式、地址、帧率或保存设置。协议／字段交叉依据[Benewake官方手册](https://ai.benewake.com/en/resources/technical-documents/tfmini-plus-user-manual/)；OE高禁用依据[NXP PCA9685手册](https://www.nxp.com/docs/en/data-sheet/PCA9685.pdf)，均不能替代实物电压与动作证据。

[连续读数工具](../../../tools/rk_i2c_acceptance.py)不写PWM寄存器；[联合工具](../../../tools/rk_dwa_readonly_stack_check.py)默认仍为只读模式，`--i2c-range`只接真实测距且未标定，`--fuse-vision`显式真实取零并向未解锁PX4送vision，`--installed-preflight`验证上述正式入口；后两者会改变估计器输入，不称纯只读。[关断工具](../../../tools/rk_pca_disable.py)只关断／休眠。[舵机工具](../../../tools/rk_servo_bench_check.py)的source模式从现有源码取角度，需现场净空确认；它验证ACK／寄存器，SHELL动作反馈另记。全部入口保留失败阻断和默认关闭的任务动作门。新增源码与工具在独立任务分支维护，既有未提交接线资料保留。
