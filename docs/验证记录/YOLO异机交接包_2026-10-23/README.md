共14个文件成员，manifest核对其中13个文件，自身不递归计算哈希；外层另有SHA256。18个包内本地链接全部可解析。训练方案及证据README已转换为包内相对链接，不依赖原项目路径；历史核查JSON中的D盘路径只表示来源。

接收端解压外层包后运行python verify_package.py（Windows也可py -3 verify_package.py），需要检查素材内部CRC时加--full-data；然后把02_给训练助手的提示词.md完整复制给另一台电脑的助手，以解压目录为工作目录。原始素材仍为内层zip，按提示词解压副本并转换，不覆盖原件。

本包不含训练好的YOLO权重、已生成的YOLO标签或实际train/val/test划分；接收端需按固定来源下载匹配YOLO／旧RKNN软件及依赖。没有附带私钥、密码、完整无人机源码或旧SSD模型。原始866MB输入和外层大包均在项目外保存，不入Git；本目录保存[核验结果](交接包核验.json)及[包内文件清单](包内文件清单.json)。

发送端“不训练”的限制不适用于已获本次SHELL授权的接收电脑。接收端应实际完成可完成的训练、评估、导出及转换，RK硬件不在场时明确保留硬件验收待办，不把电脑结果当板端验收。
