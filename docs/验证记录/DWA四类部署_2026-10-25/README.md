## 模型合同与性能边界

- 模型为包内原始best.onnx／best.rknn，不重训、不修改模型字节；标签顺序person、explosive、flammable、toxic。输入416×416 RGB，保持比例补边，conf0.5／NMS0.45。
- 实板旧API1.7.5输出维度反序报告9,H,W,3,1；逻辑输出[1,3,H,W,9]，H为52／26／13。适配器验证维度、类别、缓冲长度和有限数，再转换为解码器布局；不将五维输出直接当成普通CHW。
- [12张原固定图片对照](fourclass-cpu-rknn-comparison.json)均完成CPU ONNX与真实NPU运行，两端各输出10框，8张业务图片类别对应。两张干扰图片均被判为flammable；这不是盲测或业务精度通过证据。三头logits有量化偏差，不声明逐位相同。
- 12图真实API set/run/get耗时约650–666ms／图，约1.5次推理／秒。任务使用独立推理线程和带序号结果缓存，不重复统计同一次结果；默认5次确认窗口改为6秒。画面发布频率独立于推理频率。
