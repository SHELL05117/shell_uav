## 1. 电脑接路由器，USB进入RK

电脑连接该路由器普通Wi-Fi，RK使用2.4GHz普通网络，避免访客网络的客户端隔离。浏览器打开路由器底部管理地址，使用管理员密码登录；无需将密码提供给助手。保留USB线，通过已有FinalShell连接192.168.77.1，账户jcfh。

## 2. RK切换正式Wi-Fi，仍使用DHCP

在USB SSH内编辑已成功的专用配置：

```bash
sudo vi /etc/netplan/99-shell-wifi.yaml
```

仅将原热点access-points名称／口令换成路由器2.4GHz Wi-Fi信息，保留其他必要配置。对应片段为：

```yaml
network:
  version: 2
  wifis:
    wlan0:
      renderer: networkd
      dhcp4: true
      access-points:
        "路由器2.4GHz的Wi-Fi名称":
          password: "路由器Wi-Fi密码"
```

保留dhcp4:true，由路由器分配IPv4；本轮不向板端添加addresses／gateway4静态地址。口令仅在板端填写，不回传、截图或写入仓库。保存后：

```bash
sudo netplan apply
sudo systemctl daemon-reload
sudo systemctl restart netplan-wpa-wlan0.service
```

任何一步出现实际错误时停下处理；单独的unit changed warning按已验证的reload接续。稍后读取：

```bash
cat /sys/class/net/wlan0/address
ip -4 -br address show wlan0
ip -4 route show default dev wlan0
```

这三项用于取得实际绑定MAC、临时租约和路由器网关。早前照片MAC为14:f5:f9:e6:cd:08，仅作核对线索，最终以当前命令和路由器客户端清单一致为准；不要绑定USB主机MAC02:53:48:45:4c:02或p2p0／eth0。

## 3. 确认LAN与固定分配入口

官方该型号V1.0手册的索引给出路由设置→LAN口设置及路由设置→DHCP服务器；实际硬件版本／固件菜单以现场为准。读取LAN地址与掩码、保持DHCP开启。若LAN为192.168.1.1、掩码255.255.255.0，且192.168.1.102没有被其他设备使用，沿原规划保留该地址。若实际LAN不同，先取得信息再调整，不为套用示例盲改LAN。旧Nano的.102绑定如仍存在，改为当前RK wlan0的MAC，并保证旧设备不继续占用该地址。

优先在DHCP服务器中查地址保留／静态地址分配；若存在，添加当前wlan0 MAC及192.168.1.102，启用并保存。DHCP池是否包含保留地址按实际固件规则处理，不把地址池统一缩成单一IP。

**型号界面边界：** 该型号官方手册另列应用管理→IP与MAC绑定，并描述为ARP绑定。仅凭该名称不能断言现场固件同时提供DHCP保留；如果DHCP页没有静态分配入口，先提供LAN口、DHCP服务器和绑定页面，结合帮助提示或实际续租确认，不把ARP条目“已绑定”当作固定租约已成功。

资料：[TL-WDR6320 V1.0官方手册](https://service.tp-link.com.cn/download/202211/TL-WDR6320%20V1.0%E8%AF%A6%E7%BB%86%E9%85%8D%E7%BD%AE%E6%8C%87%E5%8D%97%201.0.0.pdf)（本轮直接打开超时，相关菜单取官方搜索索引）、[TP-Link静态分配说明](https://smb.tp-link.com.cn/service/detail_article_1976.html)、[云路由ARP绑定说明](https://smb.tp-link.com.cn/service/detail_article_2310.html)。

## 4. 保存后验证自动取址

完成确实有效的地址保留后，在USB SSH内重新关联Wi-Fi以更新租约：

```bash
sudo systemctl restart netplan-wpa-wlan0.service
```

稍等后查看ip -4 -br address show wlan0；如果仍保留旧租约，先结束正在进行的软件安装，再重启板端，使用USB重新登录检查，不立即重置路由器。目标输出为wlan0持有192.168.1.102，并能在同一路由器网络中的电脑执行：

```powershell
ssh jcfh@192.168.1.102
```

DHCP保留以板端仍dhcp4:true、重新取得指定地址、无线SSH通过为阶段结果；重启后仍获得同一地址才增加持久化通过记录。未取得这些结果前，不宣布固定IP已实现。
